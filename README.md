# 📋 주간업무보고 (Weekly Report)

자산시설관리팀의 **일일 업무 입력 → 주간 보고서 작성 → PDF 출력**을 한 화면에서 처리하는 웹 앱입니다.
데이터는 **Google 스프레드시트를 DB로** 사용하고, **Vercel 서버리스 함수**가 시트를 읽고 씁니다.

> 별도 DB 서버 없이, 이미 쓰고 있는 구글 시트를 그대로 저장소로 활용하는 것이 핵심입니다.

---

## ✨ 주요 기능

| 메뉴 | 설명 |
|---|---|
| **대시보드** | 이번주 총 업무·진행중·완료·이슈/보류·정체 업무·만료 임박 계약을 KPI 카드로 요약하고, 분류별·담당자별 업무 차트와 계약 만료 임박(D-day), 이슈 하이라이트를 표시 |
| **오늘 보고** | 날짜별로 팀원 업무(담당자·분류·업무내용·상태·우선순위·완료일)를 입력·저장 |
| **팔로우업 · 정체 업무** | 오래 진행 중이거나 보류된 업무를 자동으로 골라 후속 조치가 필요한 항목을 정리 |
| **팀원 업무** | 팀원별 주간 업무 진행 현황 |
| **시설 현황** | 사무실(지역)별 시설 이슈·조치 현황 |
| **비품 현황** | 지역·분류별 지급/입고/재고 집계. 외부 자산시트에서 **기간 기준 자동 불러오기** 지원 |
| **계약 만료** | 계약·서비스 만료일 관리 및 D-day 표시 |
| **특이사항** | 기타 보고 사항 |

### 주차 관리
- 새 주차 생성 시 지난주 미완료 업무 **자동 이월(carry forward)**
- 주차 **복제 / 이름 변경 / 삭제**
- 섹션별 `✎ 편집` 모드로 표 형태 인라인 수정

### 보고서 출력
- 인쇄 전용 스타일(`@media print`)로 팀원 업무·시설·비품·계약·특이사항을 정리된 보고서 레이아웃으로 출력
- 브라우저 인쇄 → **PDF로 저장**하여 그대로 보고에 사용

## 🏗️ 구조

```
weekly-report/
├── index.html        # 프론트엔드 (단일 파일 SPA: UI · 차트 · 인쇄 레이아웃)
├── api/
│   └── report.js     # Vercel Serverless Function — Google Sheets API 읽기/쓰기
└── package.json      # 의존성: googleapis
```

```
[브라우저 index.html] ──POST /api/report──▶ [Vercel 함수 report.js] ──Sheets API──▶ [Google 스프레드시트]
                                                                      └─(선택)──▶ [외부 자산시트]
```

### API (`POST /api/report`)

요청 형식: `{ "action": "<이름>", "args": [ ... ] }`
응답 형식: `{ "ok": true, "result": ... }` 또는 `{ "ok": false, "error": "..." }`

| action | args | 설명 |
|---|---|---|
| `getReportData` | – | 주차·담당자·전체 탭 데이터 조회 (구 형식 팀원 시트는 날짜 기반으로 자동 변환) |
| `saveWeek` | `[JSON 문자열]` | 주차 메타정보 + 시설·비품·계약·특이사항 저장 |
| `saveDay` | `[날짜, 행 배열]` | 해당 날짜의 팀원 업무 행만 교체 저장 |
| `deleteWeek` | `[주차, 시작일, 종료일]` | 주차 및 해당 기간 팀원 업무 삭제 |
| `renameWeek` | `[기존 주차명, 새 주차명]` | 주차 이름 일괄 변경 |
| `importAssets` | `[시작일, 종료일]` | 외부 자산시트에서 기간 내 지급·입고·재고·발주 수량을 지역/분류별 집계 |

## 🗂️ 스프레드시트(DB) 구성

`주간업무보고_DB` 스프레드시트에 아래 탭이 필요합니다. **1행은 헤더**, 데이터는 2행부터 저장됩니다.

| 탭 이름 | 기준 | 열 구성 |
|---|---|---|
| `설정` | 주차 | 주차 · 시작일 · 종료일 · 부서 · 상태 · 상태라벨 · 작성일 · 수정일시 |
| `M_담당자` | – | 이름 · 팀 · 직함 · 사용여부(`N`이면 제외) |
| `1_팀원업무` | 날짜 | 날짜 · 담당자 · 분류 · 업무내용 · 상태 · 우선순위 · 완료일 |
| `2_시설` | 주차 | 주차 + 6열 |
| `3_비품` | 주차 | 주차 + 6열 (구분 · 지역 · 분류 · 지급 · 입고 · 재고) |
| `4_계약` | 주차 | 주차 + 4열 |
| `5_특이사항` | 주차 | 주차 + 5열 |

**외부 자산시트(선택)** 는 헤더에 `수량`, `상태`가 있는 탭을 자동으로 찾으며, `분류/카테고리`, `지역`, `지급일`, `회수일`, `도착일` 등의 열을 사용합니다. `지역` 열이 비어 있으면 메모·매입처 등의 텍스트로 서울/부산을 추정합니다.

## 🚀 배포 방법 (Vercel)

### 1. Google 서비스 계정 준비
1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 생성 → **Google Sheets API** 사용 설정
2. **서비스 계정** 생성 → JSON 키 발급
3. DB 스프레드시트(및 외부 자산시트)를 서비스 계정 이메일(`...@...iam.gserviceaccount.com`)에 **편집자**로 공유

### 2. Vercel에 연결
1. 이 저장소를 Vercel에 Import
2. **Settings → Environment Variables** 에 아래 값 등록

| 변수 | 필수 | 설명 |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_KEY` | ✅ | 서비스 계정 JSON 키 파일의 **전체 내용** |
| `DB_SHEET_ID` | ✅ | `주간업무보고_DB` 스프레드시트 ID |
| `ASSET_SHEET_ID` | ⬜ | 외부 자산시트 ID (없으면 비품 불러오기만 비활성) |

> 스프레드시트 ID는 URL의 `https://docs.google.com/spreadsheets/d/`**`<여기>`**`/edit` 부분입니다.

3. Deploy → 배포된 주소로 접속하면 바로 사용할 수 있습니다.

### 로컬 실행
```bash
npm install
npm i -g vercel
vercel dev        # .env 또는 vercel env pull 로 환경변수 준비 후 실행
```
